Phase Months 1–4

V1 — FOUNDATION

Build the core daily loop athletes use every day and coaches rely on for basic oversight. Ship something real athletes want to log sessions in.

Identity & Auth
  • Email/password registration with verification
  • Athlete and coach profile creation (all core fields)
  • Global role system: athlete, coach, staff, org admin
  • Onboarding wizard: events → goals → coach → org invite
  • onboarded_at guard — redirect to wizard until complete
  • Password reset via signed time-limited URLs
  • Account lockout after 5 failed attempts (Redis throttle)
  • Laravel Sanctum SPA auth (cookie + CSRF)
Organizations & Teams
  • Organization creation (club / national_team types)
  • Invitation system: email → secure token → accept/decline
  • OrgLimitEnforcer: two-org rule (max 1 club + 1 national team)
  • Squad creation and athlete assignment to squads
  • Coach-athlete assignment (coach_athlete_assignments)
  • EnsureCoachOwnsAthlete middleware on all coach→athlete routes
  • Staff role: read-only access to assigned athletes only
  • Membership status lifecycle: invited → active → left / suspended
  • Nightly ExpireInvitations command
  • Membership data-access scoping by joined_at / left_at date range
Training Session Core
  • Log training session: type, date, duration, RPE, location, weather, notes
  • Sprint session logging: reps with distance, time, wind, reaction time, splits (JSONB)
  • Gym session logging: exercises, sets, weight, reps, set type, RPE
  • Shared exercise library (categories, muscle groups, movement patterns)
  • Session status workflow: logged → reviewed → approved / flagged
  • Session history with filtering by type, date, status
  • Soft delete on sessions — data never permanently destroyed
  • internal_notes field — coach-only, never exposed to athlete
Unplanned Session Detection
  • UnplannedSessionDetector checks active plan on each log
  • Sets is_unplanned = true when no plan_session_id and active plan exists
  • Dual notification: in-app + email to coach
  • unplanned_notified_at prevents duplicate alerts
  • Active plan cache in Redis (invalidated on plan changes)
  • Athletes with no active plan log freely — no flag
Performance & PRs
  • Competition creation by org admin / coach
  • Athlete registration via coach (competition_registrations)
  • Athlete logs own competition result (time in s / distance in m)
  • PRDetectionService: auto-detects new PB on result submission
  • Event type awareness: lower = better track, higher = better field
  • ON DELETE CASCADE: result deletion removes linked PersonalRecord
  • Wind reading stored — legal limit logic (≤ +2.0 m/s)
Recovery & Wellness
  • Daily wellness check-in: fatigue, soreness, mood, stress, motivation (1–10)
  • Sleep log: duration, quality, bedtime, wake time
  • One log per athlete per day enforced (unique constraint)
  • Basic trend charts on athlete dashboard
  • Partial readiness score when only one log submitted
Training Plans
  • Coach creates plan as ordered session list
  • Plan phases: base, build, peak, competition, recovery, transition
  • Assign plan to athlete with start date
  • Athlete views plan sessions on calendar
  • Basic planned vs actual session comparison
  • Link logged session to plan_session_id
  • Plan status: active → completed / cancelled
Attendance
  • Manual attendance recording by coach or admin
  • Statuses: present, absent, excused, late, partial
  • Per-session date attendance entry
  • Bulk attendance entry (POST /attendance/bulk)
  • Attendance history view per squad
Session Review & Feedback
  • Coach writes review: technique note, load note, general note
  • Action items (JSONB: text, due date, completed)
  • Coach can update review post-submission
  • Session status updated on review/approve/flag
  • Athlete notified on each status change
  • Session queue view for coaches (status=logged)
Analytics (Basic)
  • Training volume chart (weekly/monthly bar)
  • PR progression per event (line chart)
  • Session RPE trend over time
  • Basic readiness score display from available data
  • Athlete dashboard KPIs: sessions this week, days to competition, PR age
Notifications
  • In-app notification center
  • Email notifications for all key events
  • Types: session_reviewed, session_approved, session_flagged
  • Types: pr_set, pr_deleted, unplanned_session
  • Types: plan_assigned, competition_registered, invitation_received
  • Mark read / mark all read endpoints
Billing
  • Stripe integration for all four pricing tiers
  • Subscription creation, upgrade, downgrade, cancellation
  • EnforceSubscriptionLimits middleware (athlete seat count)
  • Feature flag checks per plan (hasFeature())
  • Stripe webhook handling: created, updated, payment_succeeded, payment_failed, deleted
  • Athlete data persists after org cancellation
  • Stripe customer portal route
Security & Architecture
  • UUID PKs on all tables — no sequential ID exposure
  • Laravel Policies for all resource authorization
  • ScopeToOrganization middleware on all org-scoped routes
  • CQRS-lite: Actions for writes, Query classes for complex reads
  • Domain-driven folder structure (Training, Performance, Recovery, Team…)
  • All slow ops on queues (email, ACWR, PDF)
  • Redis caching for athlete dashboard and squad overview
  • Form Request validation on every endpoint
  • RFC 7807 error format across all API responses
02
Phase Months 5–8

V2 — INTELLIGENCE

Add the analytical layer that helps coaches make better decisions and gives athletes scientific insight into their training. Introduce real-time collaboration.

Load Management (ACWR)
  • RecalculateLoadMetricsJob on every session create/update/soft-delete
  • session_load = RPE × duration_minutes (sRPE method)
  • ATL: 7-day rolling average | CTL: 28-day rolling average
  • ACWR = ATL / CTL — zones: under (< 0.8), optimal (0.8–1.3), caution (1.3–1.5), danger (> 1.5)
  • Training monotony = mean / std_dev of daily loads
  • Training strain = weekly load × monotony
  • FatigueAlertTriggered when ACWR > 1.5 → red alert to coach
  • 12-week ATL/CTL/ACWR line chart
  • ACWR gauge with zone coloring on athlete dashboard
  • Historical recalculation when past session edited (full 28-day recompute)
Readiness Score (Full)
  • ReadinessScoreCalculator with 6 weighted components
  • Sleep quality (25%), sleep duration normalized (15%)
  • Fatigue inverted (25%), soreness inverted (15%)
  • Mood (10%), load balance from ACWR (10%)
  • Score scaled to 0–100 with color labels (green/amber/orange/red)
  • RecalculateReadinessScoreJob triggered after recovery + sleep log
  • Coach squad readiness grid: all athletes color-coded
  • Recovery check-in streak tracking
Training Plans (Full Builder)
  • Week-view drag-and-drop session organizer
  • Phase tagging per plan and per week block
  • Plan template library: coach saves and reuses plans
  • PlanComplianceTracker: planned vs actual per athlete per week
  • Compliance rate dashboard per athlete and squad
  • ComplianceRateQuery — end-of-day calculation
  • DuplicatePlanAction for cloning templates
Real-time (WebSocket)
  • Laravel Reverb WebSocket server
  • Private channels: user.{'{'}id{'}'}, coach.{'{'}id{'}'}
  • Presence channels: session.{'{'}id{'}'}, squad.{'{'}id{'}'}
  • Broadcast events: LoadMetricsUpdated, SessionLogged, FatigueAlertTriggered, PersonalRecordSet
  • Coach sees athlete logging in real-time
  • Online presence indicators on squad grid
  • Dedicated broadcasts queue worker
Messaging
  • In-app direct messaging (athlete ↔ coach)
  • Squad broadcast messaging (coach → entire squad)
  • Thread types: direct, group, squad_broadcast
  • Message thread participants with last_read_at tracking
  • File attachments on messages (JSONB)
  • Pinned messages
  • SendMessageAction + BroadcastToSquadAction
Injury Management
  • Injury reporting form with body region and side selection
  • Types: strain, sprain, overuse, contusion, tendinopathy, stress_reaction, tear
  • Severity: minor, moderate, severe
  • Status: active → recovering → resolved
  • Return-to-training date tracking
  • Active injury indicator on coach squad grid
  • FatigueRiskAnalyzer: combined ACWR + injury risk signals
Advanced Analytics
  • Performance trend analysis per event with regression line
  • Seasonal periodization overview
  • Squad comparison dashboard (all athletes side-by-side)
  • CSV export for all data views
  • PDF session and performance report generation
  • 12-week load chart pre-calculated nightly by scheduler
  • PostgreSQL read replica for analytics queries
Security Additions
  • TOTP-based 2FA for coaches and admins
  • two_factor_secret encrypted at rest
  • AthletePolicy::viewForConvocation — national team cross-org read access
  • can_view_for_convocation flag: settable by org admin only
  • All convocation reads logged in audit_logs
  • Race condition guard on two-org rule (DB transaction + row lock)
UX & Frontend (V2)
  • Command palette (Cmd+K): log session, find athlete, compose message
  • Optimistic UI for all writes — rollback on error with toast
  • Inline session logging via slide-over panel (no page nav)
  • Readiness ring: animated color-transitioning circular progress
  • ACWR radial gauge with animated zone transition
  • Recovery radar chart (5 wellness dimensions)
  • AthleteLoadGrid: multi-athlete load overview table for coaches
  • Attendance drag-select grid (bulk status marking)
  • Morning digest email: SendDailyAthleteDigests (07:00 scheduler)

Phase Months 9–14

V3 — SCALE & INTELLIGENCE

Differentiate with AI-powered insights, mobile-first experience, wearable data, and a public API platform. This is the moat-building phase.

AI Features
  • Weekly AI performance summary per athlete (LLM from training data)
  • GenerateAIPerformanceSummary job on heavy queue
  • GenerateWeeklyInsightsJob (Monday scheduler)
  • Anomaly detection for unusual load or wellness patterns
  • Training recommendation engine
  • Natural language session search
  • AI summaries feature-flagged to Club Pro and Enterprise plans
Wearable Integration
  • Garmin Connect API sync
  • Polar Flow API sync
  • Apple Watch HealthKit sync
  • HRV data import → sleep logs (hrv_ms field)
  • Resting HR import → sleep logs
  • GPS session data import and route visualization
  • Auto-populate session duration from wearable data
Mobile App
  • Native iOS and Android (React Native or Flutter)
  • Full offline session logging with background sync
  • Push notifications (third channel: in-app + email + push)
  • Biometric authentication (Face ID / fingerprint)
  • Morning readiness check-in prompt
  • Wearable data sync via native device APIs
Public API Platform
  • Laravel Passport OAuth 2.0 for third-party apps
  • Developer key management
  • Webhook system for third-party integrations
  • Rate limiting and per-key usage dashboards
  • API documentation portal
  • Feature-flagged to Club Pro and Enterprise plans
Business Intelligence
  • Club admin reports: attendance rates, retention, season summaries
  • Season review PDF for federation funding submissions
  • National team selection reports
  • ProcessAttendanceReport job
  • Full athlete data export
  • End-of-season report generation command
Enterprise Features
  • SSO (SAML / OIDC) for national federations
  • White-label branding options
  • Custom plan pricing and seat limits
  • Dedicated worker node scaling
  • Advanced audit trail reporting for compliance
